# Dataset documentation

## File

`raw/abc_employee_attrition.csv`

## Source

The dataset is the public **IBM HR Analytics Employee Attrition & Performance** dataset distributed through [Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset).

## Structure

- 1,470 employee records
- 35 variables
- Target variable: `Attrition` (`Yes` or `No`)
- No missing values found
- No exact duplicate rows found

The variables cover employee demographics, compensation, satisfaction, job characteristics, performance and tenure.

## Use in this project

The raw file is read directly by both notebooks. No processed dataset is included because this phase focuses on inspection and exploratory analysis rather than model preparation.
